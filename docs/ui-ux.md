# UI and UX Notes

## Visual Direction

- Warm yellow gradient background to feel light and approachable.
- White translucent cards to soften the dense financial information.
- Navy text for calm contrast and legibility.
- Red and green reserved for expense and income meaning.

## Glanceability

- Home prioritizes today's spending and earnings first.
- View Logs shows filters above the table and visible totals before detail.
- Analytics emphasizes net balance and top category before the chart.
- Settings groups destructive controls away from preference controls.

## Interaction Patterns

- Segmented controls for quick mode switching.
- Rounded CTA surfaces for primary actions.
- Confirmation alerts on destructive actions.
- Local reminder controls exposed directly instead of hidden in submenus.

## Comfort Choices

- Large touch targets for mobile use.
- Short explanatory copy inside section cards.
- Inline empty states instead of blank pages.
- Neutral backgrounds behind critical text to reduce visual fatigue.
